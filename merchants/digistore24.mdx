This guide explains how to set up Digistore24 as a merchant. The overall flow matches the generic merchant setup; use this page for platform-specific notes.

## Step 1: Create Digistore24 Merchant
{/* SCREENSHOT: Step 1: Create Digistore24 Merchant · merchant setup screen or postback state · desktop */}

<Note>
Creating a Digistore24 merchant opens a guided setup: account details, product IDs, the postback URL and a live test, one step at a time. You can stop and come back: **Continue setup** on the merchant's row resumes it. See [Guided setup](/guides/how-to-set-up-a-new-merchant#guided-setup-for-jvzoo-clickbank-digistore24-buygoods-and-explodely). The steps below are the same settings in the merchant's full editor.
</Note>


1. Go to **Settings** → **Merchants** → **Add Merchant**
2. Select **Gateway**: Digistore24
3. Enter your **Vendor ID** as provided by Digistore24
4. Save

## Step 2: Assign Merchant to Domain
{/* SCREENSHOT: Step 2: Assign Merchant to Domain · merchant setup screen or postback state · desktop */}

1. Go to **Settings** → **Domains** → **Edit Domain**
2. Select your Digistore24 merchant
3. Save

## Step 3: Map Products
{/* SCREENSHOT: Step 3: Map Products · merchant setup screen or postback state · desktop */}

1. Go to **Settings** → **Products** → **Edit**
2. Open the **Merchant information** tab
3. Enter the **Digistore24 Product ID** for this product
4. Save

## Links and Funnels
{/* SCREENSHOT: Links and Funnels · merchant setup screen or postback state · desktop */}

Use `[BUY]`, `[UPSELL]`, and `[DOWNSELL]` tags so links auto-adapt per domain and merchant. Avoid pasting hardcoded Digistore24 checkout URLs.

## Postbacks
{/* SCREENSHOT: Postbacks · merchant setup screen or postback state · desktop */}

Click **Postback Setup** on the merchant's row in **Settings** → **Merchants**. Its steps are listed on the left: **Postback URL** (your unique URL, with **Copy**), then the setup steps for Digistore24, then **Test**. After you configure the URL in Digistore24 and click **Test IPN** (or run a test purchase), keep it open on **Test**: it checks for the postback every 5 seconds for 2 minutes and marks the merchant verified as soon as the first one arrives.

## Troubleshooting
{/* SCREENSHOT: Troubleshooting · merchant setup screen or postback state · desktop */}

- Wrong gateway on checkout: Verify the domain is assigned to Digistore24
- Link not working: Ensure product mapping has the correct Digistore24 Product ID
- Missing affiliate data: Confirm affiliate sync settings and use adaptive tags
