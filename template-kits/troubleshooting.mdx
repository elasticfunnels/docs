When a kit cannot be applied, nothing is created: your project stays exactly as it was. Fix what the message names, click **Back to review** and apply again.

## Messages on the review

| Message | What it means | What to do |
|---|---|---|
| N page URLs already exist here. Add a folder so nothing is overwritten. | Pages in your project already use some of the kit's URLs | Click the suggested **Use /folder** button, or type a folder in **Folder (optional)** |
| Use only letters, numbers, dashes and underscores. | A product code has a space or another character | Change the code, for example `sleep-gummies-1` |
| A product in this project already has this code. | The code you typed belongs to one of your products | Pick another code, or click **Use an existing product** and pick that product |
| Another product in this kit gets this code. | Two kit products have the same code | Give each its own code |
| The name can have at most 255 characters. | The product name is too long | Shorten it |

## Messages when the apply stops

| Message | What it means | What to do |
|---|---|---|
| Another kit is being added to this project right now. Try again in a minute. | A project takes one kit at a time | Wait for the other kit to finish, then apply again |
| Adding the kit took too long and was stopped. Nothing was created; try again. | The apply ran out of time | Apply again. If it happens twice, contact support with the kit name |
| Some page URLs are already taken in this project, so nothing was created. Add a folder or pick another one. | A page took one of the kit's URLs after you opened the review | Add a folder, or a different one, and apply again |
| Part of this kit is missing from the template library. Nothing was created. Tell support which kit it was. | The library copy of the kit is incomplete | Contact support with the kit name, and pick another kit meanwhile |
| A kit cannot be applied to the project it comes from. | You opened the kit inside the library's own project | Apply it to another project |
| This kit is no longer available. | The kit was removed from the library | Pick another kit |
| This project could not be found. | The project was deleted or you lost access | Switch to a project you can edit |
| A product you picked is no longer in this project. Pick another one or create it new. | A product you chose under **Use an existing product** was deleted | Pick another product, or switch the row to **Create new** |
| A product name or code cannot be used. Fix the highlighted product and try again. | A name or code broke a rule after the review checked it | Fix the highlighted row |
| Something went wrong while creating the kit. Nothing was created; try again. | An unexpected error | Apply again. If it happens again, contact support with the kit name |
| This project already has course pages at ..., and they were edited. | The kit's members pages land on course pages you changed | Add a folder so the kit's members pages go under it |

## Questions

### Why are my new products out of stock?

Kit products start with **Stock Quantity** `0` and **Out-of-Stock Policy** set to **Stop selling**. Clear **Stock Quantity** on each product, or type your real stock. See [Check the stock](/template-kits/after-applying#4-check-the-stock).

### A deleted page still blocks a URL

Deleted pages no longer block a kit URL. If one is still reported as taken, a live page uses it, either as its own URL or as the URL of one of its variants. Search **Pages** for that URL, or pick a folder.

### Can I apply the same kit twice?

Yes. Use a different folder the second time, so the URLs are free. To sell the same products from both copies, set each product row to **Use an existing product** and pick the product the first apply created.

### Can I undo a kit?

There is no undo button. The kit only adds things, so delete the pages, the funnel and the products it created if you do not want them. They are listed on the **Kit added** panel and carry the names and codes you chose.

### Why does the checkout show the kit's product name?

The kit sets **Title** from the name you typed, but **Checkout Title** keeps the kit's wording. Change it on each product. See [Check each product's titles](/template-kits/after-applying#check-the-kit-before-you-publish).

### Use on page is missing in the Images section

**Use on page** works on the pages from the apply you just ran. Open the images from **See the prompts** on the **Kit added** panel. If you opened the kit from the library, download the image and place it in the editor.
