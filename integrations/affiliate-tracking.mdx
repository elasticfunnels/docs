Automatically capturing affiliate data helps you track marketing performance across different platforms.

## How It Works
{/* SCREENSHOT: How It Works · integration settings or log state · desktop */}

- Affiliate-network postbacks are received automatically once you've configured the matching merchant or integration
- View stats on your dashboard for each affiliate individually
- Use the Tracking Link Builder to create properly formatted tracking URLs with UTM parameters for accurate attribution

## Supported Networks
{/* SCREENSHOT: Supported Platforms · integration settings or log state · desktop */}

ElasticFunnels groups affiliate-network integrations into two patterns:

- **Inbound (we receive)** — Postbacks come **from** the network so EF can record sales, refunds, chargebacks, and rebills. Setup is on the network side: paste the EF postback URL into your network account.
- **Outbound (we send)** — EF posts conversion events **to** the network so it can attribute lander or pre-lander performance. Setup is in EF: enter the network's postback URL plus the relevant click-id parameter.

### Inbound networks (postbacks → ElasticFunnels)

| Network | Auth / validation | Receives | Notes |
|---------|-------------------|----------|-------|
| [BuyGoods](/integrations/buygoods) | Postback URL only | Purchase, refund, cancel, chargeback, commission void | Auto-creates tracking pixels for BuyGoods merchants |
| [ClickBank S2S](/integrations/clickbank) | **Secret key** validation | Purchase, refund, chargeback, upsell | Same secret key you set in the ClickBank backend |
| [JVZoo Affiliate S2S](/integrations/jvzoo) | Postback URL only | Affiliate purchase, refund | Reads `tid` macro to attribute to the original click |
| JVZoo Vendor IPN | **cverify** signature | Sale, rebill, refund, chargeback, cancel | Uses your JVZoo secret key to verify v1/v2 IPNs |
| Digistore24 S2S | Postback URL only | Currently scaffolded only — full postback handling in development |

### Outbound networks (postbacks ← ElasticFunnels)

| Network | Click-id parameter | What we send |
|---------|--------------------|--------------|
| [Everflow](/integrations/everflow) | `transaction_id` (or `sub1`–`sub5`) | Purchase + macros (order_id, amount, email, currency, geo, sub1–5) |
| [RedTrack](/integrations/redtrack) | `rtkclickid` / `clickid` (or configured sub) | Purchase, refund, chargeback with `{clickid}`, `{sum}`, `{amount}`, `{currency}`, `{type}` |

<Info>
**Multiple networks at once.** EF supports running outbound integrations like Everflow and RedTrack alongside inbound networks like BuyGoods or ClickBank. Each conversion fans out to every integration whose merchant filter matches.
</Info>

## Tracking Link Builder
{/* SCREENSHOT: Tracking Link Builder · integration settings or log state · desktop */}

The Tracking Link Builder creates tracking URLs with UTM parameters for attribution across your marketing channels.

### Accessing the Tracking Link Builder

You can access the Tracking Link Builder in several ways:

<AccordionGroup>
  <Accordion title="From Tools Menu">
    1. Navigate to **Tools** in the main menu
    2. Click on the **Tracking** tab
    3. Select **Tracking Link Builder**
  </Accordion>

  <Accordion title="From Pages List">
    1. Go to **Pages** in the main menu
    2. Find the page you want to create a tracking link for
    3. Click the dropdown menu (three dots) on the page row
    4. Select **"Get Tracking Link"**
    
    The builder will automatically open with the selected page pre-filled.
  </Accordion>

  <Accordion title="From Funnels List">
    1. Go to **Funnels** in the main menu
    2. Find the funnel you want to create a tracking link for
    3. Click the dropdown menu (three dots) on the funnel row
    4. Select **"Get Tracking Link"**
    
    The builder will automatically open with the selected funnel pre-filled.
  </Accordion>
</AccordionGroup>

### How to Use the Tracking Link Builder

#### Step 1: Select Your Destination

Choose how you want to specify your destination URL:

<CardGroup cols={3}>
  <Card title="URL Tab" icon="link">
    Enter a custom URL manually. Perfect for external landing pages or specific URLs.
  </Card>
  <Card title="Page Tab" icon="file-text">
    Select an existing page from your ElasticFunnels account. The page URL will be automatically populated.
  </Card>
  <Card title="Funnel Tab" icon="sitemap">
    Select an existing funnel from your account. The funnel URL will be automatically generated.
  </Card>
</CardGroup>

#### Step 2: Choose Your Ad Platform (Optional)

Select an ad platform from the **"Auto Cost Update"** dropdown to automatically populate UTM parameters with the correct format:

- **Meta Ads** - Facebook/Meta advertising campaigns
- **Google Ads** - Google advertising campaigns
- **TikTok Ads** - TikTok advertising campaigns
- **Bing Ads** - Microsoft Bing advertising campaigns
- **LinkedIn Ads** - LinkedIn advertising campaigns

<Info>
When you select a platform, the UTM parameters are automatically populated with the correct tokens and format for that platform. You can still customize them manually if needed.
</Info>

#### Step 3: Configure UTM Parameters

The builder includes fields for all standard UTM parameters:

- **UTM Source** - The source of your traffic (e.g., "facebook", "google", "email")
- **UTM Medium** - The marketing medium (e.g., "cpc", "email", "social")
- **UTM Campaign** - The campaign name or identifier
- **UTM Term** - Keywords or ad identifiers (often used for ad names)
- **UTM Content** - Additional content identifier (often used for ad set names)

<Warning>
For proper attribution in Campaigns Management, ensure UTM parameters match your campaign structure:
- `utm_campaign` = Campaign name
- `utm_content` = Ad set name
- `utm_term` = Ad name
</Warning>

#### Step 4: Add Dynamic Tokens

Click the **"Add Token"** button next to any UTM field to insert dynamic tokens that will be replaced by the ad platform:

**Meta Ads Tokens:**

| Token | Description |
|-------|-------------|
| `{{campaign.name}}` | Campaign name |
| `{{adset.name}}` | Ad set name |
| `{{ad.name}}` | Ad name |
| `{{campaign.id}}` | Campaign ID |
| `{{adset.id}}` | Ad set ID |
| `{{ad.id}}` | Ad ID |
| `{{site_source_name}}` | Site source name |
| `{{placement}}` | Ad placement |

**Google Ads Tokens:**

| Token | Description |
|-------|-------------|
| `{campaignid}` | Campaign ID |
| `{keyword}` | Keyword |
| `{creative}` | Creative ID |
| `{adgroupid}` | Ad group ID |
| `{placement}` | Placement |
| `{device}` | Device type |
| `{network}` | Network type |
| `{matchtype}` | Match type |

**TikTok Ads Tokens:**

<Note>
Tokens are automatically replaced by the ad platform when someone clicks your link. This ensures accurate tracking even if campaign names change.
</Note>

#### Step 5: Copy Your Final Link

Once you've configured all parameters:

1. Review the **Final Link** at the bottom of the builder
2. Click the **"Copy Link"** button to copy it to your clipboard
3. Use this link in your ad campaigns

<Info>
The final link includes all UTM parameters and the `adid` parameter (automatically added based on your selected platform) for proper attribution and ad spend tracking.
</Info>

### Best Practices for Tracking Links

<Steps>
  <Step title="Use Platform Templates">
    Always select your ad platform to ensure UTM parameters are formatted correctly for that platform's requirements.
  </Step>
  
  <Step title="Match Campaign Names Exactly">
    Ensure UTM parameter values match your campaign, ad set, and ad names exactly in Meta Ads (or other platforms) for proper attribution.
  </Step>
  
  <Step title="Use Dynamic Tokens">
    Prefer dynamic tokens (like `{{campaign.name}}`) over static values when possible. This ensures tracking continues to work if you rename campaigns.
  </Step>
  
  <Step title="Test Your Links">
    After creating a tracking link, test it by clicking it and verifying the UTM parameters appear correctly in your analytics.
  </Step>
  
  <Step title="Keep Links Organized">
    Use consistent naming conventions in your UTM parameters to make reporting and analysis easier.
  </Step>
</Steps>

## Viewing Affiliate Data
{/* SCREENSHOT: Viewing Affiliate Data · integration settings or log state · desktop */}

1. Go to your main dashboard
2. Navigate to the "Analytics" or "Affiliates" section
3. Select individual affiliates to see their performance metrics
4. Filter by date ranges, products, or traffic sources

## Key Metrics Tracked
{/* SCREENSHOT: Key Metrics Tracked · integration settings or log state · desktop */}

- **Clicks**: Number of visitors from each affiliate
- **Conversions**: Sales generated by each affiliate
- **Revenue**: Total revenue attributed to each affiliate
- **Conversion Rate**: Percentage of clicks that convert
- **Average Order Value**: Average purchase amount per affiliate

## Integration with Campaigns Management
{/* SCREENSHOT: Integration with Campaigns Management · integration settings or log state · desktop */}

Tracking links created with the Tracking Link Builder work with Campaigns Management:

- **Proper Attribution**: UTM parameters ensure conversions are correctly attributed to campaigns, ad sets, and ads
- **Funnel Analytics**: When UTM parameters match your campaign structure, you'll see funnel metrics (revenue, sales, profit) in Campaigns Management
- **Ad Spend Tracking**: The `adid` parameter enables automatic ad spend tracking and ROI calculations

<Info>
For detailed information about managing campaigns and viewing unified metrics, see the [Campaigns Management](/integrations/campaigns-management) documentation.
</Info>

## Best Practices
{/* SCREENSHOT: Best Practices · integration settings or log state · desktop */}

- Regularly review affiliate performance data
- Identify your top-performing affiliates for special promotions

- **Test tracking links** before launching campaigns to verify parameters are working correctly
