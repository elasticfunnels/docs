The SlickText integration asks for an **API key**. Accounts on SlickText's older system also need a
**Private key**. **SlickText Brand ID** is optional. Saved keys are stored encrypted and never shown again.

## API key

<Steps>
  <Step title="Open API Keys">
    Log in to [SlickText](https://www.slicktext.com). Open the menu next to your name (bottom left) and go to
    **Settings** → **API & Webhooks** → **API Keys**.
  </Step>
  <Step title="Create a key">
    Click **Create API Key** and copy it. SlickText shows it only once.
  </Step>
  <Step title="Paste it in ElasticFunnels">
    Paste it into **API key**. Leave **SlickText Brand ID** blank unless your SlickText account has more than
    one brand.
  </Step>
</Steps>

## Older SlickText accounts

If your SlickText menu shows **Textwords** and has no **API & Webhooks** page, the account is on the older
system. Open **Account Settings** → **API** (click **Generate API Keys** if none are shown). Paste the
**Public Key** (starts with `pub_`) into **API key** and the **Private Key** into **Private key**.

Full setup, including keywords and lists: [SlickText integration](/integrations/slicktext).
