A Brevo sending account asks for one **API key**. Keys you save are stored encrypted and never shown again.

## API key

<Steps>
  <Step title="Open SMTP & API">
    Log in to [Brevo](https://app.brevo.com), open the menu under your account name and choose
    **SMTP & API**, or go straight to [the API keys page](https://app.brevo.com/settings/keys/api).
  </Step>
  <Step title="Generate a key">
    On the **API keys** tab, click **Generate a new API key**, name it (for example "ElasticFunnels") and
    copy it. Brevo shows it only once. It starts with `xkeysib-`.
  </Step>
  <Step title="Paste it in ElasticFunnels">
    Paste it into **API key**. It is checked with Brevo when you save.
  </Step>
</Steps>

Use the API key, not the SMTP key from the **SMTP** tab: they look alike but only the API key works here.
The same key also syncs contacts in automations.

Brevo's own guide: [API key authentication](https://developers.brevo.com/docs/api-key-authentication).

See also [Connect Brevo](/emails/sending-accounts#connect-brevo).
