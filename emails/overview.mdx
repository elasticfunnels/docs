## What are email templates?
{/* SCREENSHOT: What are email templates? · email editor or template settings · desktop */}

Email templates are the transactional emails your brand sends to customers — order confirmations, shipping notifications, renewal reminders, and more. ElasticFunnels provides **system templates** for every transaction type and lets you create **custom templates** to match your brand.

## System vs custom templates
{/* SCREENSHOT: System vs custom templates · email editor or template settings · desktop */}

| Type | Description | Editable? |
|---|---|---|
| **System** | Auto-created when you enable a merchant or subscription feature. Covers all standard transaction types (purchase, refund, shipped, etc.) | Content and design only — cannot be deleted |
| **Custom** | Templates you create from scratch for specific use cases | Fully editable and deletable |

System templates are marked with a **Locked** badge in the email list.

## Two ways to edit
{/* SCREENSHOT: Two ways to edit · email editor or template settings · desktop */}

After creating or opening an email template, you can choose between two editors:

### Visual Builder (GrapesJS)

A drag-and-drop editor that lets you design emails visually. Ideal for non-technical users who want to build responsive emails without writing HTML.

- Drag blocks like text, images, buttons, and dividers
- Style elements with a visual properties panel
- Preview desktop and mobile layouts side by side
- Insert template variables from the Variables panel
- Click **Save** in the top bar to store your changes

#### Adding sections

A **+** marker sits between the sections of the email, and above the first and below the last.
Move the pointer near one and it opens into an **Add section here** line. Click it to pick what to
insert at that spot: Text, Image, Button, Two columns, Divider, Spacer, Social links, Logo, Footer
or Custom HTML. The markers only show in the editor and are never part of the saved email.

#### Email blocks

The **Email elements** group in the blocks panel holds blocks built from tables, so they show the same
in every mail client: Button, Two columns, Spacer, Social links, Logo and Footer.
The Footer block carries your postal address and the unsubscribe link.

Blocks that only work on web pages (frontend template engine blocks, Include Component, Extends
Layout, Block and Backend Script) are hidden in the email builder. The backend If/Else, Foreach and
Set blocks are still there.

#### Your own HTML

- Drag the **HTML Block** into the email (or pick **Custom HTML** from an **Add section here**
  line) to paste markup of your own. The canvas shows it rendered, as it will look in the inbox.
  Click it to edit the code.
- To change the markup of any element, right-click it and choose **Edit HTML**, or select it and
  press `Cmd+E` / `Ctrl+E`.

### Code Editor (Monaco)

A full HTML code editor for users who prefer writing markup directly. The code editor gives you complete control over the email HTML.

- Syntax highlighting for HTML/CSS
- Auto-completion and error detection
- Save with `Cmd+S` / `Ctrl+S`
- Switch to the Visual Builder at any time

## Campaign emails

A new campaign opens on a ready-made layout: your brand name, a headline, a short text, a button
and a footer with your postal address and the unsubscribe link. Edit it in place instead of
starting from an empty page. On the campaign's **Content** step, **Replace content** lets you start
over from **A template**, **An earlier campaign** or **The default layout**.

Click **Edit design** to open the layout in the Visual Builder, or **Edit HTML** to open it in the
Code Editor. When the builder was opened from a campaign, the top bar also shows **Continue to settings**:
it saves the email and takes you to the campaign's **Settings** step.

## Versions

Every time you save a template with a changed subject, preview text, sender, reply-to address or
content, the previous content is kept as a version you can read but not edit, and the template
moves to the next version number. Saving without changing any of those (renaming the template,
adding a builder comment) does not make a new version.

To see them, open the template's settings (the edit dialog) and look under **Versions**. Click
**View** on a version to read its subject, sender and body. There is no restore button: to go back
to an older version, copy what you need from it into the template and save.

Each send records the template and the version it used, so the [email log](/emails/troubleshooting#start-with-the-email-log)
can show exactly what went out. A campaign keeps the version it had when it started sending:
editing the template while the campaign is going out changes later sends of the template, not the
rest of that campaign.

## Template variables
{/* SCREENSHOT: Template variables · email editor or template settings · desktop */}

Every email template has access to **variables** — dynamic data that gets replaced when the email is sent. For example, `{{ purchase.customer_first_name }}` is replaced with the customer's actual first name.

Variables are organized by **scope** (purchase, subscription, brand, etc.). See the [Template Variables](/emails/template-variables) reference for the complete list.

## Conditional content
{/* SCREENSHOT: Conditional content · email editor or template settings · desktop */}

Use `@if` / `@endif` directives to show or hide sections based on available data:

```html
@if(purchase.tracking_url)
<a href="{{ purchase.tracking_url }}">Track Your Package</a>
@endif
```

Use `@each` / `@endeach` to loop over collections like products:

```html
@each(product in products)
<p>{{ product.name }} — ${{ product.total }}</p>
@endeach
```
